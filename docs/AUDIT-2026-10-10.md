## 一、P0 — 阻断性缺陷（8 项）

### 1. 多轮对话上下文丢失 + 会话永久降级
**根因**：`src/lingxi/agent/graph.py:130-152` 每轮向 `ainvoke` 传入完整 initial state，破坏了 LangGraph 的 reducer 语义。

| 字段 | reducer | 实际行为 |
|---|---|---|
| `messages` (`state.py:56`) | LastValue | 每轮被 `[system, 当前 user]` 整段覆盖，历史丢失 |
| `step_count` (`state.py:59`) | `lambda x, y: x + y` | 跨轮累加，永不重置 |

**实测**：
```
第1轮: step_count=1  reply='好的，我来帮你'
第2轮: step_count=2  reply='好的，我来帮你'
第3轮: step_count=3  reply='好的，我来帮你'
第4轮: step_count=3  reply='这个问题我需要多一点时间思考…'   ← LLM 一次都没被调用
LLM 累计调用次数 = 3（max_steps=3）
```
```
第2轮 LLM 实际收到的 messages：
  [system] SP
  [user] 那它什么时候到？        ← 第1轮"我的订单号是 A123"完全不可见
```

**影响**：用户问"那它什么时候到？"机器人不知道"它"是什么。而 `TicketStore` 里 4 条消息完整保留 —— 存储层与推理层脱节。这是客服产品的命脉级故障。

**修复方向**：`thread_id` 固定（`graph.py:148`）时不能再传完整 initial state；`step_count` 必须每轮从 checkpoint 重置或改用非累加语义；`messages` 应由 LangGraph 自己累积，或从 `ticket.messages` 重建。

## 二、P0 — 安全防线空洞（4 项，Layer 2-3）

### 9. 人格护栏在长度截断中被整块砍掉
`src/lingxi/persona/injector.py:93-99` 超预算时直接 `result[:self._max_chars]` 尾截断，而安全护栏排在拼接序列**最后**（`injector.py:81-82`）。
```
输出长度 = 1500 (max_chars=1500)
含身份锚 '智犀'      : True
含安全护栏 '安全护栏' : False    ← 护栏消失
```
即：配了长 `custom_prompts` 后，"护栏兜底"变成"护栏最先牺牲"。有 `persona_overflow` 告警但无降级策略。

### 10. 注入检测存在教科书级绕过 + 正常对话误伤
`src/lingxi/persona/guardrails.py:31-40`：
```
[block] 'ignore previous instructions'          ← 正确拦截
[clean] 'ignore all previous instructions'     ← 绕过（正则要求 all 紧跟 instructions）
[clean] 'IGNORE ALL PREVIOUS INSTRUCTIONS'     ← 绕过
[clean] '请忘记你的地址'                        ← 中文变体绕过
[block] 'forget your password'                 ← 误伤（正常客服对话被硬拦截）
[block] 'forget your name'                     ← 误伤
```
根因：`forget\s+(…|your)\s+(instructions?|rules?|settings?)?` 末组可选；`(?i)` 未处理字符间插空格（`I G N O R E`）。

### 11. `detect_injection` 全仓零调用点 —— 三道防线缺两道
`src/lingxi/persona/guardrails.py:8` 声称"三道防线"，实际：
- 第 1 道（身份锚前置）：有效
- 第 2 道（注入检测）：`detect_injection` 仅在 `persona/__init__.py` 再导出与 `tests/` 使用，**生产路径从未调用**
- 第 3 道（权限硬编码）：存在但被 #6 的默认放行绕过

`nodes.py:44` 只调 `detect_role_override`，而后者（`guardrails.py:150-162`）仅统计 system 消息数量 >1，`graph.py:130-133` 恒构造 1 条 → **该分支永不可达**。

### 12. 记忆渲染预算溢出导致整块记忆静默消失
`src/lingxi/memory/pipeline.py:66-69` 首条超预算即 `break`：
```
单条 3000 字记忆 + max_chars=1500 -> ''
```
`injector.py:64` 的 `if m.memory_injection and memory_block` 把空串当假值 → `[用户记忆]` 整块消失且无日志。
